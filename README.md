# Package build scripts for Plamo Linux

Plamo Linux のパッケージ作成用のビルドスクリプト、パッチ、設定ファイル等を管理するリポジトリーです。

main ブランチは空です。実際は次のブランチを使用します。

| ブランチ名 | 説明 |
| --- | --- |
| plamo-8.x | Plamo 8.x 用のスクリプト |
| plamo-9.x | Plamo 9.x 用のスクリプト |

次のブランチも常時存在しますが、現時点ではこのブランチを使用しているのは特定のメンテナーのみです。


| ブランチ名 | 説明 |
| --- | --- |
| update-8.x | Plamo 8.x でパッケージを更新する際に更新するブランチ。更新後に plamo-8.x にマージ |
| update-9.x | Plamo 9.x でパッケージを更新する際に更新するブランチ。更新後に plamo-9.x にマージ |
